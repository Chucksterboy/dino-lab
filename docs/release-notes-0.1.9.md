# Dino Lab 0.1.9

The first public Windows release of Dino Lab, an interactive companion for The Isle: EVRIMA.

## Included

- 22 playable species and eight wildlife entries, with species artwork and growth controls.
- Independent Source 1 and Source 2 statistics, Prime/Frail conditions, growth charts, movement, survival and attack analysis.
- Six-specimen comparisons and a sortable species statistics table.
- 41 active mutations with Universal, Carnivore and Herbivore filters, listed strengths and unlock conditions.
- Mutation scenarios for both sides of an attack matchup, with eligible damage bonuses, conditional incoming resistance and live hit estimates.
- A rotating multicolor DNA icon, opening/flipping book, glowing comparison exchanges, animated statistics bars and a bubbling flask.
- A 3.5-second startup animation, reduced-motion preferences, favorites, saved comparisons and close-to-tray behavior.
- Built-in checks for newer stable GitHub releases.

## Windows downloads

- **Dino-Lab-0.1.9-Windows-Setup.exe** — Windows installer.
- **Dino-Lab-0.1.9-Windows-Portable.exe** — standalone application.
