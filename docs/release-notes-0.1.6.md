# Dino Lab 0.1.6

- Added a colorful Mutations reference tab with all 43 supplied guide entries, search, diet/category filters, strengths, unlocks and restrictions. The two removed entries are in a historical section.
- Added independent attack mutation scenarios for both combatants, including conditional damage bonuses, incoming reduction, starting health and bleeding conditions. Counts update in both directions; the result panel stays visible while editing.
- Kept unpublished mutation behavior explicit through selectable stacking assumptions and Hypermetabolic ranges/manual scenarios. Stamina-only effects do not silently become health damage reduction.
- Removed the requested source explanations, growth captions and footer strips, patch labels, comparison metadata and Growth Dynamics log button.
- Removed BabyBoar, BabyDeer and BabyGoat from all visible species lists and selectors, including old saved comparisons. Eight adult wildlife entries remain.
- Replaced the sidebar tab icons with consistent icons for the species guide, comparison, statistics table and mutations.

Original captured source records remain intact internally. See MUTATIONS-SOURCES.md and MUTATION-COMBAT-MODEL.md for the mutation data and calculation scope.
