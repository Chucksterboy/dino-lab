# Dino Lab 0.1.21

- Moved combat out of species profiles into a dedicated **Combat Arena** main tab.
- Added a continuously animated clashing-swords navigation icon, with cyan/coral blades and amber impact sparks. Reduced motion keeps a static icon; hidden/minimized windows pause animation.
- Added two large animated portraits using the same dinosaur artwork as the species library. Each updates immediately with its species selection.
- Placed independent species selectors, growth stages, Prime/Frail condition and HP bars beneath the two portraits.
- Preserved selected attacks, two-way hit counts, mutation bonuses and resistance, entombment levels, stacking, bleeding, Hypermetabolic ranges and health-scaled bite force.
- Retained all 22 playable dinosaurs, including Hypsilophodon's existing Source 2 values, and eight adult wildlife entries. Saved attack overrides now apply to both sides.
- Included the 0.1.20 health penalty and attack-reference cleanup: full damage at 50% HP and above, scaling to half damage at 10% HP, with no further reduction below 10%.
